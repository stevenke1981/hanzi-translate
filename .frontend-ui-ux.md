# Frontend UI/UX design context

## Product
AquaMoon is the future-facing root brand for a small collection of focused web
apps. The current production app is 譯匠 (Yijiang), a Traditional Chinese-first
translation and text-conversion tool at `translate.aquamoon.app`. This task adds
the root `aquamoon.app` informational homepage as the AdSense review entry.

## Target audience and usage context
People discovering AquaMoon from search or a shared link, usually on a phone or
desktop, who need to understand the brand quickly and open the relevant app.
The page is public and low-risk, but must be trustworthy enough for an ad-site
review and clear enough for first-time visitors.

## Primary user jobs
- Understand what AquaMoon is and which product is available; success is a
  clear path to the 譯匠 app.
- Confirm privacy, terms, and advertising transparency; recovery is direct
  access to the legal pages without a login or paywall.

## Desired tone
Calm, precise, and quietly optimistic: short plain-language sections, stable
layout, restrained blue accents, clear hierarchy, and no surprise motion or
claims about unreleased products.

## Existing implementation stack
React 19, TypeScript, Vinext/Vite, Cloudflare Worker/Sites, and existing CSS
custom properties in `app/globals.css`. Reuse the existing brand mark, tokens,
buttons, cards, footer, responsive breakpoints, and semantic HTML. Validate with
the repository lint, build, test, and browser checks.

## Constraints
Keep `translate.aquamoon.app` behavior unchanged, preserve `.openai/hosting.json`
and the Sites/Vinext architecture, avoid new UI dependencies, keep the root
page crawlable without login, and do not fill AdSense IDs or submit account
information in source control. Formal DNS/deployment remains a separate
confirmed action.

## Accessibility and inclusive design target
Use semantic landmarks, one clear h1, keyboard-reachable links, visible focus,
adequate contrast, responsive reflow at 390px, and no essential information that
depends on color or animation.

## Languages, locales, and content resilience
The root brand page is Traditional Chinese-first with concise English labels
only where useful. Preserve CJK line wrapping, avoid fixed-width text blocks,
and keep legal links understandable in both existing interface languages.

## Visual references
Use the existing 譯匠 visual grammar: blue/navy palette, generous whitespace,
rounded cards, and a direct primary action. This is a principle-level reuse;
do not clone another company's trade dress, copy, or assets.

## Non-goals
AdSense account creation, payment or identity verification, ad approval,
publisher/ad-unit IDs, a CMS, a second hosting project, or a new product
dashboard.
